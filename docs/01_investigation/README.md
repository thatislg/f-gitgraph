# 01. Hồ Sơ Khảo Sát & Phân Tích Kỹ Thuật (Investigation & Audits)

Thư mục này lưu trữ toàn bộ các hồ sơ khảo sát, kiểm toán kiến trúc, phân loại năng lực Git và lộ trình tiến hóa của dự án F-GitGraph theo từng giai đoạn:

---

## Danh Mục Các Thư Mục Khảo Sát

1. **[phase3_Reborn/](phase3_Reborn/README.md)**:
   - Hồ sơ khảo sát và kiểm toán toàn diện cho Phase 3 Reborn:
   - `001_Git_Features_Comprehensive_Taxonomy.md`: Bảng phân loại 12 trụ cột Git CLI và năng lực GUI client.
   - `002_Fpgitgraph_Current_Capabilities_Audit.md`: Kiểm toán 45 tiêu chí năng lực hiện tại của F-GitGraph.
   - `003_Gap_Analysis_And_Evolution_Blueprint.md`: Ma trận khoảng cách và lộ trình tiến hóa 4 giai đoạn (3.1 đến 3.4).
   - `004_Design_System_And_Visual_Identity.md`: Quy chuẩn thiết kế Cyber-Lab, đinh tán chữ thập góc (`+`), bảng màu Neon.
   - `005_Audio_Feedback_And_Sound_Design.md`: Thiết kế phản hồi âm thanh vi mô Web Audio API.

2. **[phase2_Investigation/](phase2_Investigation/README.md)**:
   - Hồ sơ khảo sát đa nền tảng và nghiên cứu mở rộng sang macOS / Linux.

3. **[phase1_Avatar/](phase1_Avatar/README.md)**:
   - Toàn bộ hồ sơ nghiên cứu và thiết kế nút lục giác Hexagon, Avatar ClipPath, Zoom 5x, và Neon Ambient Gradient.

4. **[core_git/](core_git/README.md)**:
   - Hồ sơ phân tích điểm nghẽn hiệu năng của TypeScript backend cũ và kiến trúc nhân F# Native AOT ban đầu.
